
# Downloads oficiais — Ecoscard

Este repositório disponibiliza versões compiladas
das aplicações Ecoscard destinadas aos clientes.

## Aplicações disponíveis

### EcosDataPrepConfigMultosPrivateSmart

Aplicação para Windows.

[Consultar versões disponíveis](../../releases)

## Como instalar

1. Acesse a Release correspondente à aplicação.
2. Baixe o arquivo ZIP para seu sistema operacional.
3. Extraia o conteúdo em uma pasta.
4. Consulte as instruções de configuração.
5. Execute a aplicação.
